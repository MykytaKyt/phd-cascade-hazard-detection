# Каскадне виявлення небезпечних подій у відеоспостереженні

Програмна реалізація та експерименти дисертаційної роботи на здобуття ступеня доктора філософії
«Дослідження та розробка методів глибокого навчання для виявлення небезпечних подій на основі зорового спостереження»
(М. О. Кит, Харківський національний університет радіоелектроніки, кафедра прикладної математики).

Попередня реалізація, на яку посилаються опубліковані статті, зберігається без змін у репозиторії
[human-fall-detection](https://github.com/MykytaKyt/human-fall-detection). Цей репозиторій містить
уточнені експерименти та нові результати дисертації.

## Принцип відтворюваності

Кожне число, таблиця та рисунок дисертації отримуються одним скриптом з `experiments/`
і зберігаються в `results/` (числа) або `figures/` (рисунки). Значення вручну в текст не переносяться.

## Структура

```
src/thesis/
  kinematic/     шар відокремлення динаміки (DDL), екстрапольований центр мас, мережа LTC
  routing/       маршрутизація: асиметрична область, конформний вибір порогу, задача з обмеженнями
  changepoint/   найшвидше виявлення розладки (CUSUM) на виході кінематичного класифікатора
  fusion/        комбінування свідчень Демпстера–Шафера (бінарна та K-класова рамка)
  vlm/           клієнт мультимодальної моделі, кешування відповідей
  vad/           виявлення довільних небезпечних подій (UCF-Crime): CLIP-скоринг, сегменти, метрики
experiments/     скрипти за розділами дисертації
results/         числові результати (json/csv)
figures/         рисунки, що генеруються скриптами
tests/           модульні тести
docs/            план дисертації, перелік відомих проблем, математичні виведення
tools/           допоміжні інструменти (перевірка бібліографії)
references.bib   список використаних джерел
```

## Встановлення

```bash
pip install -e ".[dev]"
```

Python ≥ 3.10.

## Бібліографія

Усі джерела зберігаються в `references.bib`. Кожен запис містить DOI або URL і поле `verified`
з датою перевірки. Перевірка доступності DOI та відповідності метаданих:

```bash
python tools/check_refs.py references.bib
```
