# Комбінування свідчень на K-класовій рамці

Чернетка до розділів 2, 4, 5 (блок Г). Узагальнює твердження 2 UzhNU (бінарна рамка).

## 1. Позначення

Рамка розрізнення $\Theta = \{\theta_1, \dots, \theta_n\}$, $n = |\Theta|$. BBA джерела s: $m_s : 2^\Theta \to [0, 1]$,
$m_s(\varnothing) = 0$, $\sum_A m_s(A) = 1$. Кон'юнктивне комбінування S джерел за один крок:

$$
m_\cap(A) = \sum_{A_1 \cap \dots \cap A_S = A} \prod_s m_s(A_s), \qquad K = m_\cap(\varnothing).
$$

Правило Демпстера: $m_D(A) = m_\cap(A)/(1 - K)$, A ≠ ∅. Правило Ягера: $m_Y(A) = m_\cap(A)$ для A ≠ ∅, Θ,
$m_Y(\Theta) = m_\cap(\Theta) + K$. Пігністичне перетворення $BetP(\theta) = \sum_{A \ni \theta} m(A)/|A|$;
для множини гіпотез B ⊆ Θ $BetP(B) = \sum_{\theta \in B} BetP(\theta)$.

Позначимо $S(B) = \sum_{\theta \in B}\sum_{A \ni \theta,\ A \ne \varnothing} m_\cap(A)/|A|$ (пігністична маса
ненормованого кон'юнктивного результату).

**Лема Г0.** $BetP_D(B) = S(B)/(1 - K)$ і $BetP_Y(B) = S(B) + K\,|B|/n$.

*Доведення.* Для Демпстера — лінійність BetP за масою. Для Ягера маси всіх A ≠ ∅, Θ збігаються з $m_\cap$, а
маса Θ збільшена на K, що додає $K/n$ до BetP кожної гіпотези. ▫

## 2. Рішення за максимумом

**Твердження Г1.** Для будь-якої скінченної рамки і будь-яких BBA, комбінованих за один крок, рішення
$\arg\max_\theta BetP(\theta)$ за правилами Демпстера і Ягера збігаються.

*Доведення.* За лемою Г0 обидві величини — строго зростаючі афінні перетворення тієї самої S(θ), однакові для
всіх θ (множник $1/(1-K) > 0$ і зсув $K/n$). ▫

Наслідок: висновок UzhNU «перехід до правила Ягера не змінює жодного рішення» не залежить ні від бінарності
рамки, ні від вигляду BBA, якщо рішення приймається за максимумом.

**Зауваження.** Для послідовного попарного комбінування трьох і більше джерел правило Ягера не асоціативне
(маса конфлікту першого кроку бере участь у наступних як маса Θ), тому твердження Г1 стосується однокрокового
комбінування всіх джерел.

## 3. Порогові рішення за асиметричних втрат

За асиметричних втрат рішення про тривогу приймається не за максимумом, а за порогом:
тривога, якщо $BetP(B) \ge \beta$, де B — множина «небезпечних» гіпотез. Якщо BetP трактувати як
імовірність, байєсівський поріг для втрат $C_{FN}$, $C_{FP}$ дорівнює $\beta^* = C_{FP}/(C_{FN} + C_{FP})$,
тобто $\beta^* \ll 1/2$ за $C_{FN} \gg C_{FP}$.

**Твердження Г2.** Порогові рішення $BetP(B) \ge \beta$ за правилами Демпстера і Ягера збігаються для всіх
BBA тоді й лише тоді, коли $\beta = |B|/n$. Якщо $\beta < |B|/n$, то тривога за правилом Демпстера тягне тривогу
за правилом Ягера (правило Ягера менш схильне до пропусків за конфлікту); якщо $\beta > |B|/n$ — навпаки.

*Доведення.* За лемою Г0
$BetP_D(B) \ge \beta \iff S(B) \ge \beta(1 - K)$ і $BetP_Y(B) \ge \beta \iff S(B) \ge \beta - K|B|/n$.
Різниця порогів $\beta(1-K) - (\beta - K|B|/n) = K(|B|/n - \beta)$ дорівнює нулю для всіх K лише за
$\beta = |B|/n$; за $\beta < |B|/n$ поріг Ягера нижчий, тож множина тривог Демпстера міститься в множині тривог
Ягера; за $\beta > |B|/n$ — навпаки. ▫

**Наслідки.**

1. Бінарна рамка, B = {θ_A}: рішення збігаються лише за β = 1/2. За пріоритету безпеки ($\beta^* < 1/2$)
   правило Ягера дає не менше тривог, ніж правило Демпстера, і різниця зростає з конфліктом K — це
   формальне обґрунтування вибору правила Ягера саме для асиметричних втрат (а не лише як захисту від
   контрінтуїтивних результатів за великого K).
2. Ієрархічна рамка UCF-Crime (13 типів подій + «норма», n = 14), B — усі типи подій: $|B|/n = 13/14$.
   Будь-який практичний поріг $\beta < 0.93$ робить правило Ягера суворо більш схильним до тривоги за конфлікту.
3. Для вибору між правилами вирішальними є не величина K, а положення порогу β відносно |B|/n.
