# План дисертації

Тема: «Дослідження та розробка методів глибокого навчання для виявлення небезпечних подій на основі зорового спостереження».
Спеціальність: 113 Прикладна математика (уточнити відповідність новому переліку).
Науковий керівник: Єсілевський В. С., к.т.н., доцент.
Зразок структури та оформлення: дисертація Гольдінера Д. І. (ХНУРЕ, кафедра ПМ, 2024).

## 1. Наскрізна лінія

Ключова ідея — каскад: дешевий кінематичний класифікатор працює постійно, важка мультимодальна модель (VLM)
викликається лише тоді, коли це обґрунтовано асиметричним функціоналом втрат, а суперечливі висновки рівнів
поєднуються за теорією Демпстера–Шафера.

Еволюція методу:

1. Мобільна відеоплатформа (YOLO → MediaPipe → SAM → CLIP → Llama 3.2 на кожному кадрі): пілот ~77 %,
   висока вартість — мотивація каскаду.
2. Математична модель каскаду: оптимальна маршрутизація, властивості правила комбінування, умова доцільності.
3. Перший рівень — кінематичний фільтр (DDL + LTC); другий рівень — семантична верифікація та злиття свідчень.
4. Узагальнення на довільні небезпечні події (бійки, пограбування, ДТП тощо): CLIP-скоринг → маршрутизація → VLM.

## 4. Нові математичні результати

**А. Маршрутизація з гарантією повноти (розділ 2).**
Задача мінімізації функціонала втрат за обмежень Recall ≥ R_min і N_VLM ≤ B; доведення порогової структури
оптимальної політики через функцію Лагранжа. Конформний вибір порогу τ_N на відкладених послідовностях
зі скінченновибірковою гарантією P(Recall ≥ R_min) ≥ 1 − δ. Експеримент — за позазгортковими ймовірностями, без VLM.

**Б. Падіння як задача найшвидшого виявлення розладки (розділи 2, 4).**
CUSUM на логіт-виході LTC замість покадрового порогу; метрики рівня події: затримка виявлення та середній час
до хибної тривоги (ARL); умови гарантованої затримки; маршрутизація за накопиченою статистикою.
Мотивація: більшість невиправлених пропусків — перші кадри сегментів падіння.

**В. Динаміка маятника (розділ 3).**
Екстрапольований центр мас ξ = x + ẋ/ω₀, ω₀ = √(g/L) (Hof, 2005) у нормованих координатах зображення;
лема про обмеженість стану та ліпшицевість виходу дискретизованої LTC (стійкість до шуму ключових точок).

**Г. DST на K-класовій рамці (розділи 2, 5).**
Узагальнення тверджень 2–3 на |Θ| = K; умови збігу рішень правил Демпстера і Ягера; ієрархічна рамка
«аномалія/норма → тип події».

**Д. Стійкість до похибки калібрування (розділ 2).**
Оцінка надлишкових втрат маршрутизації за |P(y | p) − p| ≤ ε.

## 5. Наукова новизна (робоче формулювання)

1. Вперше запропоновано математичну модель каскадної системи виявлення небезпечних подій з оптимальною
   маршрутизацією за асиметричних втрат і доведено порогову структуру оптимальної політики за обмежень на
   повноту та бюджет звернень (А, Д; робота 1).
2. Вперше запропоновано метод конформного вибору порогу маршрутизації зі скінченновибірковою гарантією повноти (А).
3. Вперше задачу виявлення падіння сформульовано як задачу найшвидшого виявлення розладки на виході кінематичного
   класифікатора та отримано умови гарантованої затримки виявлення (Б).
4. Удосконалено метод комбінування свідчень Демпстера–Шафера: неперервне кінематичне свідчення, умови збігу
   рішень правил Демпстера і Ягера на K-класовій рамці (Г; роботи 1, 3).
5. Набули подальшого розвитку кінематичні моделі виявлення падінь: екстрапольований центр мас у нормованих
   координатах зображення, доведена стійкість дискретизованої LTC (В; робота 2).
