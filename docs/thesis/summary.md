# РОЗШИРЕНЕ РЕЗЮМЕ ДИСЕРТАЦІЇ

**Кит М. О. Дослідження та розробка методів глибокого навчання для виявлення небезпечних подій на основі зорового
спостереження.** Науковий керівник — к.т.н., доц. Єсілевський В. С. Спеціальність 113 «Прикладна математика».

## 1. Математична задача

За послідовністю кадрів $X_1, X_2, \dots$ потрібно прийняти рішення, чи настала небезпечна подія (падіння людини;
у загальному випадку — будь-яка подія з переліку, заданого текстом). Задача має три особливості:

- **асиметричні втрати:** пропуск події значно дорожчий за хибну тривогу, тому критерієм є функціонал
  $L = C_{FN}N_{FN} + C_{FP}N_{FP} + C_{VLM}N_{VLM}$ з обмеженням на повноту, а не середня точність;
- **джерела інформації різної вартості:** дешева модель може обробляти кожен кадр, але погано розуміє контекст;
  мультимодальна модель (VLM) розуміє сцену, але один запит до неї коштує на порядки більше (≈ 5 с проти ≈ 0.07 с на кадр);
- **подія має початок:** рішення приймається для послідовності, і важлива затримка виявлення.

Отже, це задача **послідовного прийняття рішень за двома джерелами інформації різної вартості** з обмеженнями на
повноту і бюджет запитів.

## 2. Що не розв'язано в існуючих моделях (розділ 1)

| Модель | Недолік щодо цієї задачі |
|---|---|
| Оцінювання пози (теплові карти, PAF, регресія координат) | покадрові оцінки без відкаліброваної невизначеності, без динаміки |
| Біомеханічні моделі стійкості (перевернутий маятник, XCoM) | сформульовані в 3D, потребують калібрування камери |
| Нейромережеві моделі часової динаміки | оцінки не є ймовірностями; немає гарантій частки пропусків |
| Відмова від рішення, каскади моделей | оптимізують середні втрати, не враховують обмежень на повноту і бюджет |
| CUSUM, оцінка Лордена | потребують незалежних спостережень з відомим відношенням правдоподібності |
| Теорія Демпстера–Шафера | вибір правила комбінування за асиметричних втрат не обґрунтовано |
| Методики оцінювання | поріг за тестовими мітками, покадрові метрики, розмітка «лежання» замість «падіння» |

## 3. Основні теоретичні результати (розділ 2)

1. **Оптимальна політика запитів двопорогова** (твердження 2.1–2.3): запит до дорогого джерела робиться лише
   для $p_t \in (\tau_N, 1 - \tau_A)$; за асиметричних втрат область несиметрична; обмеження на повноту визначає лише
   нижній поріг. *Звідси випливає каскадна структура системи* — вона не постулюється, а виводиться (п. 2.10).
2. **Конформний вибір порогу** (твердження 2.4): гарантія $\mathbb{E}[\text{частка невиправних пропусків}] \le \alpha$ без
   припущень про калібрування; потрібно щонайменше $n \ge 1/\alpha - 1$ записів з подією, для гарантії з імовірністю
   $1-\delta$ — $n \ge \ln(1/\delta)/(2\alpha^2)$.
3. **Похибка калібрування** (твердження 2.5–2.6): для оптимальності порогів вона має другий порядок малості, але
   розрахунок межі повноти за калібруванням для гарантій непридатний.
4. **Комбінування свідчень** (твердження 2.7–2.8): на будь-якій скінченній рамці рішення за максимумом
   пігністичної ймовірності для правил Демпстера і Ягера збігаються, а порогові рішення — лише за $\beta = |B|/n$.
5. **Умова доцільності** (2.15)–(2.17): дороге джерело вигідне лише за достатньої розрізнювальної здатності;
   отримано вимогу до його робочої точки $(TPR_V, FPR_V)$.
6. **Розладка** (твердження 2.11–2.13): умова гарантованої затримки; для виходу класифікатора на перекритих вікнах
   гарантія CUSUM погіршується з $Te^{-h}$ до $TWe^{-h/W}$, а гарантія покадрового правила зберігається.

Розділ 3 додає модель дешевого джерела: **перевернутий маятник і екстрапольований центр мас у координатах
зображення** (без калібрування камери) і **мережу з рідкою часовою сталою** (1 753 параметри) з доведеною
обмеженістю стану, оцінкою чутливості і сертифіковано стійким навчанням.

## 5. Наукова новизна (коротко)

1. Вперше: математична модель прийняття рішення за двома джерелами різної вартості, двопорогова структура
   оптимальної політики, каскад як наслідок.
2. Вперше: конформний вибір порогу маршрутизації з гарантією повноти і мінімальний обсяг калібрування.
3. Вперше: умова доцільності звернень до дорогого джерела як вимога до його робочої точки.
4. Вперше: виявлення падіння як задача найшвидшого виявлення розладки з мітками «падіння»; межі оцінки Лордена.
5. Удосконалено: комбінування свідчень Демпстера–Шафера (неперервне свідчення класифікатора, збіг правил).
6. Подальший розвиток: екстрапольований центр мас без калібрування камери, стійкість мережі з рідкою часовою
   сталою, сертифіковано стійке навчання.
